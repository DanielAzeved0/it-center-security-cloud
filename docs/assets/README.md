# Assets

Esta pasta guarda recursos visuais da documentacao.

## Estrutura

```text
assets/
|-- diagrams/
`-- images/
```

Pastas `diagrams/` e `images/` ainda nao foram criadas neste repositorio — este documento descreve a convencao para quando existirem. Hoje, prefira diagramas em texto (mermaid/ASCII) dentro dos proprios documentos Markdown.

## Diagramas

Pasta: `diagrams/`.

Use esta pasta para armazenar:

* diagramas exportados;
* fontes de diagramas;
* imagens de arquitetura.

## Imagens

Pasta: `images/`.

Use esta pasta para imagens de apoio a README e documentacao.

Evite armazenar:

* screenshots sensiveis;
* imagens com secrets;
* arquivos pesados/grandes sem necessidade.
